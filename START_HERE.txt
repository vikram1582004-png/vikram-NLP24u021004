WINDOWS QUICK START
-------------------
1. Install Python 3.10 or newer.
2. Open Command Prompt in this folder.
3. Run:
   py -m venv venv
   venv\Scripts\activate
   pip install -r requirements.txt
4. Optional LLM mode:
   copy .env.example .env
   Edit .env and set OPENAI_API_KEY.
   The default model in the example is gpt-5.6-luna.
5. Start prototype:
   streamlit run app.py
6. Benchmark:
   python evaluate.py

EASIEST METHOD
--------------
Double-click run_demo.bat. It creates the virtual environment, installs the dependencies,
and starts Streamlit.
